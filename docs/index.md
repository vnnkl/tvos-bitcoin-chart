# Bitcoin Terminal

A terminal-style Bitcoin market monitor for Apple TV. Full-screen candlestick charts, live order book, trade feed, and STRC filing data — rendered like a proper trading terminal, from your couch.

## Support

Found a bug or have a feature request? [Open an issue on GitHub](https://github.com/vnnkl/tvos-bitcoin-chart/issues).

## Privacy

Bitcoin Terminal collects no data whatsoever. Read the full [privacy policy](./privacy/).

## Disclaimer

Bitcoin Terminal displays publicly available market data for informational purposes only. Nothing in the app is financial advice.
